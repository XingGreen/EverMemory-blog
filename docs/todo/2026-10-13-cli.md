## 3. 注意与坑

1. **改 env 必须重新部署才生效**——Vercel 官方原文：changes only apply to new deployments; the running deployment keeps its old values。忘了 redeploy 是最常见的错误。
2. **用 `vercel --force` 清 build cache**，否则可能复用旧构建、env 不更新。
3. **轮换 `ADMIN_JWT_SECRET` 等价"全踢"**：旧 JWT 验签失败，KV 会话表无需清理——这也是它比"清 KV"更根本的原因（KV 可能被同时攻陷，见计划推论 3）。
4. **Secret 变量 write-only**：`vercel env` 保存后不可回读。
5. **敏感值走 stdin 管道**，不要放进命令行参数；仍要留意 shell history。
6. **CLI 只能改 env，不能改 KV**：清 KV 需 Upstash 控制台/API，或 `vercel env pull` 后跑脚本。
7. **PowerShell 陷阱**：不要用 `Set-Content` 写含中文的文件（会变 GBK / BOM）；提交信息用 `git commit -F <file>`。
